# Dual-Stack Network Simulation

A Cisco Packet Tracer simulation of an eight-site network using IPv4 and IPv6. The project demonstrates VLSM subnetting, OSPF routing, and network services including email, FTP, and DHCPv6.

## Open the Simulation

Download [dual-stack-network.pkt](dual-stack-network.pkt) and open it in Cisco Packet Tracer. Use the **Logical** workspace to explore the topology.
